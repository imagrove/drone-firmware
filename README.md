# drone-firmware

Firmware, example projects and desktop tools for the ESP32 Drone documented at **[drone.imagrove.com](https://drone.imagrove.com)**.

👉 **[Firmware & tools rebuild — progress tracker](https://github.com/imagrove/drone-firmware/issues/1)**
